# BookNest

Domowa biblioteka w Pythonie, Flasku i SQLite. Można prowadzić spis książek i sprawdzać, komu i do kiedy zostały pożyczone.

## Uruchomienie

```bash
python -m pip install -r requirements.txt
python app.py
```

Aplikacja działa pod adresem http://127.0.0.1:5000. Przykładowe dane można dodać do pustej bazy poleceniem `python seed.py`.

Testy: `python -m pytest`.
